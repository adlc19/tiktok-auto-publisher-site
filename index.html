Video publishing utility for TikTok

TikTok Auto Publisher is a desktop utility that helps a user schedule and publish their own videos to TikTok accounts that they have explicitly authorized, using TikTok's official developer APIs.

What this app does

The application runs on the user's computer. The user selects or schedules local video files, connects one or more TikTok accounts through TikTok's authorization flow, and the application sends the selected content to TikTok for publication.

The application is not a social network, does not sell user data, and does not provide a public account-management website.

How the TikTok integration works

  1. The user starts the application on their own computer.
  2. The user authorizes the application through TikTok Login Kit.
  3. The application receives the authorization credentials needed for the selected TikTok API features.
  4. The application submits the user's selected video to TikTok using the Content Posting API.
