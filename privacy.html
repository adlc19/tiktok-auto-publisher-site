Privacy Policy

This Privacy Policy explains how TikTok Auto Publisher handles information when you use the desktop application.

1. Data controller / operator

This application is operated by Adim Lachkam EI. Contact: [adim1904@hotmail.com].

2. Information handled by the application

The desktop application may handle the following information locally on the user's computer:

  • TikTok account authorization information required by the TikTok API;
  • TikTok profile identifiers returned during authorization;
  • video files, captions, scheduling information, and publication settings selected by the user;
  • local application logs and publication status information.

3. Where the information is processed

The application is designed to run locally on the user's computer. The operator does not provide a central application server for uploading the user's videos or storing the user's TikTok credentials.

Video content and the TikTok account data required for publication are transmitted to TikTok when the user asks the application to publish content. TikTok's own privacy policy and terms govern TikTok's processing of that information.

4. Storage of authorization credentials

The application is designed to store authorization tokens locally using the computer's credential/keychain facilities where supported. Users should protect access to their computer and operating-system account.

5. Information sharing

The operator does not sell or rent personal information. The application sends data to TikTok only as required to perform the TikTok actions requested by the user and as permitted by the configured TikTok API scopes.

6. Third-party services

The TikTok API is a third-party service. Its handling of personal data is governed by TikTok's policies, which are separate from this Privacy Policy.

7. Data retention and deletion

Because the application is designed to operate locally, users can delete local application data, scheduled files, logs, and stored authorization credentials from their computer. A user can also revoke the application's authorization through the relevant TikTok account settings or developer authorization flow, subject to TikTok's available controls.

8. Security

No software can guarantee absolute security. Users should keep their operating system, application dependencies, and account credentials secure and should not share their TikTok client secret or local token storage with others.

9. Children's privacy

The application is not intended to be directed at children. Users should comply with TikTok's age requirements and all applicable laws.

10. Changes to this policy

This policy may be updated when the application's data practices change. The latest version will be published on this page with an updated date.

11. Contact
